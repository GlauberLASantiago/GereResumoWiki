📖 Gerador de Resumos da Wikipédia

O Gerador de Resumos da Wikipédia é uma aplicação web simples e elegante de página única (SPA) que permite pesquisar termos na Wikipédia e gerar automaticamente um cartão HTML estilizado com o resumo do artigo. Este código gerado está pronto a ser copiado e incorporado em qualquer outro website, blogue ou projeto.

✨ Funcionalidades

🔍 Pesquisa em Tempo Real: Integração direta com a API REST da Wikipédia em português.

🎨 Múltiplos Temas Visuais: Escolha entre 6 estilos de cartões diferentes para combinar com o design do seu projeto:

Moderno (Padrão)

Sofisticado (Tons de lilás/taupe)

Modo Escuro

Minimalista

Clássico / Retrô

Neon / Cyberpunk

Material Design

👀 Pré-visualização Dinâmica: Veja exatamente como o cartão ficará antes de copiar o código.

📋 Cópia num Clique: Botão integrado para copiar o código HTML final (com estilos inline aplicados) diretamente para a área de transferência.

📱 Design Responsivo: Interface da aplicação totalmente adaptável a dispositivos móveis e computadores.

🛠️ Tecnologias Utilizadas

HTML5

JavaScript (Vanilla) para manipulação do DOM e chamadas à API.

Tailwind CSS (via CDN) para a estilização da interface da aplicação.

Wikimedia REST API para a obtenção dos dados enciclopédicos.

🚀 Como Utilizar

Como este projeto consiste num único ficheiro HTML, não é necessário instalar dependências ou configurar um servidor complexo.

Faça o clone deste repositório:

git clone [https://github.com/SEU_USUARIO/NOME_DO_REPOSITORIO.git](https://github.com/SEU_USUARIO/NOME_DO_REPOSITORIO.git)


Navegue até à pasta do projeto.

Abra o ficheiro index.html em qualquer navegador web moderno (Chrome, Firefox, Safari, Edge).

Digite um termo na barra de pesquisa (ex: "Inteligência Artificial"), escolha um estilo no menu pendente e clique em "Buscar".

Clique no botão "Copiar HTML" e cole no seu site!
